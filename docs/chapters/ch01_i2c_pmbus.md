# 第一章：I2C / PMBus 波形診斷與數位波形檢視

## 這個頁面在做什麼？

I2C 是嵌入式系統中最常見的通訊匯流排，連接 EEPROM、溫度感測器、電源管理 IC、GPIO 擴充器等。
當 I2C 通訊失敗時，光看程式碼的回傳值（如 `-EIO`）無法知道「為什麼」失敗。
你需要看邏輯分析儀抓到的 SCL/SDA 波形，才能判斷是硬體問題還是韌體邏輯錯誤。

## 怎麼操作？

1. 進入 GUI 第 1 頁 **「📊 I2C / PMBus 診斷與波形檢視」**。
2. 點擊 **「載入內建測試波形」** 或上傳自己的 Saleae CSV。
3. 頂部顯示 4 大 KPI 卡片（總交易數、異常數、頻率、Jitter）。
4. 切換到不同分頁查看詳細結果。

## 怎麼看懂 KPI 卡片？

| KPI | 白話解釋 | 怎麼判讀？ |
|---|---|---|
| **總傳輸次数** | 抓到了幾筆完整的 START→STOP 通訊 | 數量太少可能是抓取時間不夠長 |
| **異常事件數** | 偵測到幾個 NACK、Clock Stretch、Bus Hang 等異常 | 0 表示完全正常，>0 需要點開異常面板排查 |
| **平均時鐘頻率** | SCL 的平均速度 | 100 kHz = Standard-mode, 400 kHz = Fast-mode |
| **時鐘抖動 (Jitter)** | 頻率變異百分比 | <15% 正常；>35% 表示 ISR 延遲或匯流排負載過重 |

## 怎麼看懂數位波形圖？

切換到 **「📈 數位方波與協定軌」** 分頁，選擇任一筆交易：

- 上方彩色區塊 = 協定階段標註
- 中間青色線 = SDA（資料線）
- 下方黃色線 = SCL（時鐘線）

**怎麼讀波形？**

| 波形特徵 | 白話解釋 | 排查方向 |
|---|---|---|
| SCL 高電平時 SDA 從高變低 | START 條件 | 正常的通訊起始 |
| SCL 高電平時 SDA 保持穩定 | 資料取樣點 | 此時的 SDA 就是該 bit 的值 |
| 第 9 個 Clock Pulse SDA 為低電平 | ACK（確認） | Slave 正常回應 ✅ |
| 第 9 個 Clock Pulse SDA 為高電平 | NACK（否認） | Slave 沒有回應 ❌ |
| SCL 被 Slave 拉低很久不放 | Clock Stretching | Slave 忙碌中，超過 25ms 就有問題 |
| SCL 高電平時 SDA 從低變高 | STOP 條件 | 正常的通訊結束 |

使用 `examples/data/i2c_golden.csv` 進行演練。此檔案包含：
- PCA9548A MUX Channel 切換 (0x70)
- EEPROM 寫入/讀取 (0x50)
- LM75 溫度感測器讀取 (0x48)
- PCA9555 GPIO 讀取 (0x20)
