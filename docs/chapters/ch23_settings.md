# Ch23 — 偏好設定

## 功能簡介

偏好設定（Settings & Preferences）頁面提供全域參數與環境選項的集中化管理介面。工程師可在此調整協定分析引擎之判定門檻（如 I2C Timeout）、資料列數讀取上限、SPI 分頁大小，以及切換介面語系（繁體中文 / 英文）與視覺主題配色。

所有設定均具備即時生效與一鍵還原預設值功能，並於頁面底部提供直觀的「目前生效設定摘要」資訊看板。

---

## 可配置項目詳解

頁面提供 5 項核心偏好設定，各參數規格如下：

### 1. I2C 預設 Timeout (ms)
- **預設值**：`25.0 ms`
- **數值範圍**：`1.0 ~ 1000.0 ms`（步進 1.0 ms）
- **功能說明**：設定 I2C 與 SMBus 交易之 Clock Stretching（時鐘延展）超時判定門檻。若從端拉低 SCL 超過此設定值，分析引擎將標註 `SMBUS_TIMEOUT_EXCEEDED` 異常。

### 2. 預設語言（Locale）
- **預設值**：`zh-TW`
- **可選項目**：`zh-TW`（繁體中文）、`en-US`（English）
- **功能說明**：切換工具之操作介面文字、表格標題、圖表標籤與診斷提示語系。

### 3. 預設主題（Theme）
- **預設值**：`暗色 (Dark)`
- **可選項目**：
  - **暗色 (Dark)**：深色背景，適合實驗室弱光環境與長時間除錯。
  - **亮色 (Light)**：標準明亮背景，適合高環境光與文件截圖。
  - **高對比度 (High Contrast)**：增強邊界與文字對比度，提升視覺可讀性與無障礙體驗。
- **功能說明**：切換全域視覺 CSS 主題配色。

### 4. 分析資料列數上限（Max Rows）
- **預設值**：`250,000` 列
- **數值範圍**：`1 ~ 10,000,000` 列（步進 10,000 列）
- **功能說明**：限制單次匯入分析之最大 CSV 或交易記錄行數，防範超大擷取檔導致瀏覽器記憶體超載或頁面卡頓。

### 5. SPI 預設 Page Size (Bytes)
- **預設值**：`256 Bytes`
- **數值範圍**：`1 ~ 65536 Bytes`（步進 256 Bytes）
- **功能說明**：設定 SPI NOR Flash Page Program（頁面寫入，0x02）指令之預設緩衝區大小。當連續寫入位元組超過分頁邊界時，分析引擎將觸發 `PAGE_BOUNDARY_WRAPPED` 警示。

## 操作步驟

1. 透過側邊欄導覽至 **「偏好設定（Settings & Preferences）」** 頁面。
2. 依實際除錯需求修改各欄位數值或下拉選單。
3. 點擊 **「套用設定」** 按鈕（主要操作按鈕）：
   - 系統將設定值即時寫入全域狀態（`st.session_state`）。
   - 同步更新語系翻譯登錄表與視覺主題。
   - 畫面右上角彈出「設定已成功套用！」成功 Toast 提示。
4. 若欲回復出廠設定，點擊 **「重設為預設值」** 按鈕，所有數值將立即復原。

## 即時生效設定摘要

頁面底部常駐顯示 5 組 Metric 狀態卡片，方便工程師隨時確認當前生效之全域環境配置：

| 指標卡片 | 顯示範例 | 說明 |
|---|---|---|
| **I2C Timeout** | `25.0 ms` | 當前生效之 I2C 逾時門檻 |
| **語言** | `zh-TW` | 當前系統語系代碼 |
| **主題** | `暗色 (Dark)` | 當前介面主題名稱 |
| **資料上限** | `250,000 列` | 當前最大分析列數限制 |
| **SPI Page** | `256 B` | 當前 SPI 預設 Page Size |

---

## 生效範圍與生命週期

- **當前工作階段有效**：設定套用後立即對目前瀏覽器分頁之所有協定診斷頁面生效。
- **全域引擎共用**：例如在偏好設定中調整的 I2C Timeout，將直接作為 I2C 診斷頁面與批次分析引擎的判定基準。
- **瀏覽器重整與持久性**：目前設定保存在當前 Streamlit Session 中；若重新啟動伺服器或開啟全新無痕視窗，系統將以預設常數初始化。
