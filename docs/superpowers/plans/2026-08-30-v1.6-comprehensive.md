# v1.6.0 Comprehensive Enhancement — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close test coverage gap (78.55% -> 85%+), add protocol timing/statistics modules for SPI/UART/PCIe/MCTP, build a unified multi-protocol report generator, and add CSV data export for all protocol analysis results.

**Architecture:** 8 independent work streams: 4 coverage tasks, 4 protocol statistics modules, unified report, and CSV export. Coverage tasks touch only test files. Statistics modules are self-contained per-protocol additions. Report and CSV export are new modules with GUI/CLI integration.

**Tech Stack:** Python 3.12, Streamlit, Plotly, Typer/Rich (CLI), Pydantic, fpdf2 (optional), uv

**Spec:** `docs/superpowers/specs/2026-08-30-v1.6-comprehensive-design.md`

## Global Constraints

- Python >= 3.10 compatibility (no tomllib, use tomli)
- All commands via `uv run`
- Traditional Chinese (zh-TW) UI text, English CLI help text
- Zero-LaTeX policy
- Git identity from existing config (no override)
- mypy + ruff + pytest must all pass
- No new runtime dependencies (csv is stdlib)
- EvidenceMetric pattern for any metric that might lack source data
