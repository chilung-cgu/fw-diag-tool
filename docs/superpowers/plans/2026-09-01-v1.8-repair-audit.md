# v1.8 Repair and Regression Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repair existing Streamlit navigation regressions and verify the project without adding new product features.

**Architecture:** Centralize registered page objects and route metadata, then make Dashboard links resolve through that registry. Add runtime-context tests and a differential regression matrix against v1.7.0; preserve all existing page behavior.

**Tech Stack:** Python 3.10+, Streamlit 1.62, AppTest, pytest, uv, ruff, mypy, MkDocs.

**Spec:** `docs/superpowers/specs/2026-09-01-v1.8-repair-audit-design.md`

## Global Constraints

- Repair only; do not add new user-facing capabilities.
- Do not bump package version, rewrite tags, push, or merge to `main`.
- All commands use `uv run`.
- Internal navigation uses registered `st.Page` objects; no arbitrary HTML or external URLs.
- Runtime claims require AppTest/navigation-context evidence, not bare helper calls.
- Keep Traditional Chinese and English behavior unchanged except for error wording needed by the repair.
