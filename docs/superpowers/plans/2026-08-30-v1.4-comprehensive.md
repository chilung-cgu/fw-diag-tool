# v1.4.0 全面優化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix all known bugs, add PCIe/MCTP diff engines, add Batch & Settings GUI pages, enhance HTML reports with print CSS/TOC/collapsible sections, wire accessibility, update documentation — bringing fw-diag-tool to v1.4.0.

**Architecture:** Parallel independent tasks feeding into an integration commit. Each diff engine, GUI page, and HTML enhancement is self-contained with its own tests.

**Tech Stack:** Python 3.10+, Streamlit 1.62, Plotly, Pydantic 2, pytest, ruff, mypy

**Spec:** `docs/superpowers/specs/2026-08-30-v1.4-comprehensive-design.md`

## Global Constraints

- Python >= 3.10 (no tomllib)
- All commands via `uv run`
- zh-TW for all UI strings
- Zero LaTeX policy
- Follow existing patterns: frozen dataclass results, classmethod compare, render() entry point
- Git identity from existing `~/.gitconfig` — never override
- ruff + mypy clean after each task
