# v1.7.0 Comprehensive Enhancement — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add interactive statistics charts, SPI flash chip database, UART symptom database, PCIe topology tree, MCTP EID topology map, documentation update, and coverage gap closure.

**Architecture:** 8 independent work streams that can be executed in parallel. Each task creates self-contained modules with dedicated tests, then integrates into existing GUI/CLI/reporter infrastructure.

**Tech Stack:** Python 3.12, Streamlit, Plotly, Typer/Rich (CLI), uv

**Spec:** `docs/superpowers/specs/2026-08-30-v1.7-comprehensive-design.md`

## Global Constraints

- Python >= 3.10 compatibility (no tomllib, use tomli)
- All commands via `uv run`
- Traditional Chinese (zh-TW) UI text, English CLI help text
- Zero-LaTeX policy in all output
- Git identity from existing config (no override)
- mypy + ruff + pytest must all pass after each task
- No new runtime dependencies (Plotly is already available via Streamlit)
- Frozen dataclasses for all new data structures
- EvidenceMetric pattern for any metric that might lack source data
