# v1.4.0 全面優化設計規格

> **版本目標**：修復全部已知 bug、補齊協定對稱性、新增 GUI 頁面、增強 HTML 報告、改善 UX、完善文件。

## 1. Bug 修復與技術債

### 1.1 fuzz_lab_ui.py mypy 錯誤修復
- **問題**：7 個型別錯誤源自 protocol union 未正確窄化。`report` 變數宣告為 `I2CAnalysisReport` 但後續被賦值 `SPIReport` 和 `UARTReport`。
- **方案**：使用 `I2CAnalysisReport | SPIReport | UARTReport | Any` union 型別，或在每個分支中引入獨立的區域變數避免重新賦值。
- **驗證**：`uv run mypy src/fw_diag_tool/` 0 errors。

### 1.2 PAGE_INDEX 去重
- **問題**：`page_index.py` 和 `shared.py` 各自維護一份幾乎相同的 `PAGE_INDEX`，新頁面（Protocol Diff、Session Compare）只存在於 `page_index.py`。
- **方案**：`shared.py` 移除重複定義，統一從 `page_index.py` import。

### 1.3 shared.py 拆分
- **問題**：892 行的 `shared.py` 職責過多（本地化對照表、分析函式、session 控制、page footer、語言選擇器、search/breadcrumb）。
- **方案**：拆為 `shared.py`（核心 helpers）、`localization_maps.py`（翻譯對照表）。保持 `from shared import *` 向後相容。

## 2. 協定對稱性

### 2.1 PCIe Diff 引擎
- **新檔案**：`src/fw_diag_tool/pcie/diff.py`
- **模型**：`PCIeDiffResult` dataclass，比對 vendor/device ID、link degradation、AER 錯誤清單、data quality issues。
- **類別**：`PCIeDiffEngine.compare(baseline: PCIeConfigSpace, candidate: PCIeConfigSpace) -> PCIeDiffResult`
- **Pattern**：完全對齊 `SPIDiffEngine` / `UARTDiffEngine` 的介面慣例。

### 2.2 MCTP Diff 引擎
- **新檔案**：`src/fw_diag_tool/mctp/diff.py`
- **模型**：`MCTPDiffResult` dataclass，比對 message count、IPMB frame count、error count、message type 分佈差異。
- **類別**：`MCTPDiffEngine.compare(baseline: ServerMgmtReport, candidate: ServerMgmtReport) -> MCTPDiffResult`

### 2.3 Protocol A/B Diff 頁面擴展
- **修改**：`protocol_diff_ui.py` 新增 PCIe 和 MCTP 支援。
- **_PROTOCOLS** 擴展為 `("I2C", "SPI", "UART", "PCIe", "MCTP")`。
- PCIe 接受 lspci hex dump / txt 輸入；MCTP 接受 hex bytes 輸入。

## 3. 新 GUI 頁面

### 3.1 Batch Analysis GUI
- **新檔案**：`src/fw_diag_tool/gui/pages/batch_ui.py`
- 允許上傳多檔案，選擇協定，一鍵批次分析。
- 結果表格顯示每個檔案的摘要、異常數、健康狀態。
- 支援一鍵下載全部報告（ZIP）。

### 3.2 Settings / Preferences 頁面

- 預設 I2C timeout、預設語言、預設主題、預設協定。
- 使用 `st.session_state` 持久化。
