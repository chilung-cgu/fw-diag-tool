# fw-diag-tool v1.3.0 — 功能強化與 UX 優化 Design Spec

> **Date:** 2026-08-30
> **Status:** Approved
> **Scope:** Fix critical bugs, surface existing unused engines as GUI pages, integrate cross-cutting UX improvements.

## 1. Problem Statement

The project has several high-value engines already implemented but not exposed through the GUI:
- Three protocol diff engines (`i2c/diff.py`, `spi/diff.py`, `uart/diff.py`) with no GUI page
- A session comparator (`session/comparator.py`) with no GUI page
- A toast notification system (`gui/notifications.py`) not integrated into analysis pages
- A critical bug in `reporting/batch.py` (F821: undefined `report` variable)
- HTML report generator lacking print-friendly layout and interactive features

## 2. Changes

### 2.1 Fix batch.py Critical Bug (Task 1)

`reporting/batch.py` lines 171-188: variable `i2c_report` is assigned but `report` (undefined) is used in downstream calls. Fix: rename `i2c_report` → `report` or adjust references. Also fix any remaining ruff violations.

### 2.2 Protocol Diff Comparison Page (Task 2)

New page: `gui/pages/protocol_diff_ui.py`

- Unified A/B comparison for I2C, SPI, and UART protocols
- User uploads or pastes baseline + candidate data
- Calls existing `I2CDiffEngine`, `SPIDiffEngine`, `UARTDiffEngine`
- Displays structured diff results: new/resolved/common anomalies, transaction count delta
- Visual delta summary with color-coded metrics (green=resolved, red=new)
- Registered in `app.py` navigation under "Advanced Analysis" category

**Inputs:** Two files/text areas per protocol (baseline + candidate)
**Outputs:** Structured diff result table, summary metrics, downloadable Markdown report

### 2.3 Session Comparison Page (Task 3)

New page: `gui/pages/session_compare_ui.py`

- Upload two `.fwsession.json` files (baseline + candidate)
- Calls existing `compare_sessions()` from `session/comparator.py`
- Displays: verdict (improved/degraded/unchanged), metric deltas, protocol match
- Side-by-side metric cards with delta indicators
- Downloadable comparison report

**Inputs:** Two `.fwsession.json` files
**Outputs:** SessionComparison result visualization, downloadable JSON/Markdown

### 2.4 Dashboard Health Check Panel (Task 4)

Enhance `gui/pages/dashboard_ui.py`:

- Add a "System Health Check" expander section
- Run same checks as `fw-diag doctor` CLI: Python version, core deps, optional deps, example data
- Display results as a checklist with ✓/✗/⚠ status indicators
- Show overall health score (all core checks pass = healthy)

### 2.5 Toast Notification Integration (Task 5)

Integrate `gui/notifications.py` toast system into analysis pages:

- I2C diagnosis: toast on analysis complete/error
- SPI analysis: toast on analysis complete/error
- PCIe analysis: toast on analysis complete/error
- UART analysis: toast on analysis complete/error
- MCTP analysis: toast on analysis complete/error
- Session save/load: toast on success/failure
- File upload: toast on format detection

Use `show_success_toast()` for completions and `show_error_toast()` for failures.

### 2.6 HTML Report Enhancement (Task 6)

Enhance `reporting/html_report.py`:

- Add print-friendly CSS media query (`@media print`)
- Add collapsible sections using `<details><summary>` HTML elements
- Add table of contents generation from Markdown headings
- Add report metadata header (tool version, timestamp, protocol)
- Add light theme variant for HTML reports
- Keep the existing dark theme as default
