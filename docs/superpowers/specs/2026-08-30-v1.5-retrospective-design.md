# v1.5.0 Comprehensive Enhancement — Retrospective Design Spec

> **Note:** This is a retrospective spec, written after implementation to document
> the design intent and decisions. Phase B was implemented without the formal
> brainstorming → approval → writing-plans flow. This document exists so future
> contributors can understand *why* these changes were made.

**Date:** 2026-08-30
**Version:** 1.5.0 (follows v1.4.0 tag `cdb5d37`)

## Goal

Close the functional symmetry gaps identified during a deep post-v1.4.0 audit:
every protocol that has an analysis engine should also have CLI diff, correlation
timeline support, session save/export, and structured JSON export. Additionally,
strengthen i18n coverage, Dashboard UX, and project documentation.

## Gap Analysis (post-v1.4.0)

| Gap | Evidence |
|-----|----------|
| CLI `pcie diff` / `mctp diff` missing | `fw-diag pcie --help` shows only `analyze`; I2C/SPI/UART all have `diff` |
| Correlation UI only I2C/SPI/UART | `correlation_ui.py` imports only 3 protocol parsers |
| Session save only on I2C page | `rg session_io gui/pages/` returns only `i2c_diagnosis.py` |
| Diff results lack JSON export | Protocol Diff UI only offers Markdown download |
| i18n keys incomplete for new pages | batch_ui / settings_ui use hardcoded strings in places |
| Dashboard lacks dependency health check | No version/status panel for runtime dependencies |
| README outdated | Does not reflect v1.4.0 features or page count |

## Design Decisions

### 1. CLI Diff Symmetry
- Add `pcie diff` and `mctp diff` to `cli.py`, following the established
  pattern of `spi diff` and `uart diff`.
- Accept baseline + candidate file paths, call existing diff engines, output
  Rich-formatted tables.

### 2. Correlation UI Extension
- Extend `build_timeline_events()` to accept PCIe and MCTP reports.
- PCIe events: BDF discovery, link degradation, AER errors, dmesg timestamps.
- MCTP events: packet parsing, IPMB checksum errors, sequence mismatches.
- Add PCIe/MCTP upload columns and example-load buttons.

### 3. Session Export Symmetry
- Add `serialize_*_session()` and `replay_*_session()` to `session_io.py`
  for SPI, UART, PCIe, MCTP.
- Each GUI page gets a "Save Session" button after analysis completes.
- Standard v2 session schema with protocol, summary, anomaly_count.

### 4. Diff JSON Export
- Add `to_dict()` / `to_json()` to all 5 diff result classes.
- Add `format_protocol_diff_json()` in protocol_diff_ui.py.
- Add JSON download button alongside existing Markdown download.

### 5. i18n Completeness Audit
- AST-based scan of all `t()` and `_tr()` calls across GUI pages.
- Add ~40 missing keys to `gui.py` domain.
- Refactor batch_ui and settings_ui to use i18n functions.
- Create automated completeness test.

### 6. Dashboard Enhancement
- Environment health panel: Python + 5 key dependency versions with status.
- Analysis history: Plotly bar chart from MetricsCollector protocol_usage.
- Quick session import: load most recent .fwsession.json with one click.

### 7. README Update
- 26-page GUI capability matrix table.
- v1.5.0 highlights section.
- Full CLI command reference including all diff subcommands.

## Testing Strategy
- Each feature area has its own test file.
- Target: grow from 977 (v1.4.0) to 1034+ tests.
- All changes must pass mypy, ruff, and existing test suite.
